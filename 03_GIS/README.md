# Study Kasus 3 — Career and Competition in Industrial Era with GIS

## Permasalahan
Calon pelaku UMKM ingin membandingkan beberapa kandidat lokasi dengan mempertimbangkan koordinat dan jarak ke fasilitas umum.

## Tujuan
- Membaca data koordinat.
- Menghitung jarak garis-lurus menggunakan rumus Haversine.
- Membuat peringkat awal berdasarkan jarak terdekat ke fasilitas.

## Implementasi
Jalankan `python src/analisis_lokasi.py`. Dataset berisi titik dummy di sekitar Kota Bengkulu. Jarak yang dihitung adalah jarak geodesik garis-lurus, bukan jarak tempuh jalan.
