# Study Kasus 4 — Introduction to Machine Learning

## Permasalahan
Membantu menyaring kandidat lokasi UMKM menggunakan fitur numerik dan label kelayakan yang sudah tersedia pada data latihan.

## Tujuan
- Memisahkan data latih dan uji.

## Implementasi
Jalankan `python src/klasifikasi_lokasi.py`. Label dalam dataset adalah label sintetis untuk pembelajaran, bukan penilaian pakar atau rekomendasi nyata.
