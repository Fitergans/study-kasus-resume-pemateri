# Study Kasus 5 — Human-Computer Interaction & Data Visualization

## Permasalahan
Pemilik UMKM membutuhkan tampilan sederhana yang membantu membaca tren omzet tanpa harus memahami kode.

## Tujuan
- Menyajikan data secara visual.
- Menyediakan filter produk.
- Menerapkan prinsip HCI dasar: label jelas, konsistensi, ringkasan utama, dan grafik yang mudah dibaca.

## Implementasi
Jalankan:
```bash
pip install -r requirements.txt
streamlit run src/dashboard.py
```
Dashboard memakai dataset penjualan contoh yang ada di folder `data`.
