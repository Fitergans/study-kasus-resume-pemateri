# Paket Study Kasus 6 Materi Pemateri

Paket ini berisi enam study kasus berdasarkan tema resume materi. Setiap folder memuat:
- `README.md`: latar belakang, tujuan, langkah menjalankan, dan interpretasi.
- `data/`: dataset contoh/dummy untuk latihan.
- `src/`: implementasi Python yang dapat dijalankan.
- `requirements.txt`: pustaka tambahan bila diperlukan.

## Menjalankan
1. Ekstrak ZIP.
2. Pastikan Python 3.10+ terpasang.
3. Buka terminal pada folder study kasus yang ingin dicoba.
4. Instal kebutuhan: `pip install -r requirements.txt`
5. Jalankan perintah yang tercantum pada README di folder tersebut.

Semua dataset yang disertakan merupakan data sintetis/dummy untuk pembelajaran, bukan data resmi atau hasil penginderaan jauh aktual. Untuk publikasi GitHub, sertakan atribusi jika nantinya mengganti dataset dengan data eksternal.

## Daftar kasus
1. Analytics & AI — analisis penjualan dan prediksi sederhana.
2. HPC — perbandingan komputasi serial dan paralel untuk tantangan lokal.
3. GIS — pemetaan sederhana fasilitas/UMKM dan analisis jarak.
4. Machine Learning — klasifikasi kelayakan lokasi UMKM.
5. HCI & Data Visualization — dashboard interaktif ringkas.
6. Deforestation Alerts — demonstrasi pemrosesan citra sintetis dan deteksi perubahan.

## Catatan
Kasus nomor 6 hanya demonstrasi alur algoritmik menggunakan citra sintetis. Jangan menganggap keluarannya sebagai peringatan deforestasi nyata. Analisis operasional memerlukan citra satelit yang sesuai, koreksi atmosfer/geometrik, validasi lapangan, dan evaluasi model.
